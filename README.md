# 전남한국줄넘기협회 홈페이지

전라남도 줄넘기 종목단체(전남한국줄넘기협회)를 위한 **정적 웹사이트**입니다.
빌드 도구·프레임워크 없이 HTML / CSS / Vanilla JS만으로 제작되어, 어떤 정적 호스팅에도 그대로 올릴 수 있습니다.

> ℹ️ **데이터 출처**
> 2026-10-31 기준, 협회 회신(확인요청서 A·B·D 항목)으로 받은 내용만 게재되어 있습니다.
> 사무국 정보, 임원 명단, 조직도, 공식 로고, 2026 연간 일정, 참가비, 경기 종목, 12개 시·군 지부는
> 협회가 직접 확인해 준 값입니다. 회신이 오지 않은 항목(자격 급수 체계, 등록 클럽 현황,
> 개인정보처리방침 등)은 **추측으로 채우지 않고 "준비 중"으로 비워 두었습니다.**
> 반영 내역과 남은 요청 항목은 [`docs/협회회신_반영내역.md`](docs/협회회신_반영내역.md),
> 초기 조사 근거는 [`docs/RESEARCH.md`](docs/RESEARCH.md)에 정리되어 있습니다.

## 1. 빠르게 보기

```bash

python3 -m http.server 8000

npx http-server -p 8000
```

## 3. 디렉터리 구조

```
.
├── index.html … contact.html      생성된 정적 페이지 (배포 대상)
├── assets/
│   ├── css/style.css              디자인 시스템 + 전체 스타일
│   ├── js/main.js                 슬라이더 · 드로어 · 탭 · 아코디언 · 카운터 · 테마
│   └── img/favicon.svg
├── robots.txt / sitemap.xml
├── docs/RESEARCH.md               자료조사 결과 및 출처
└── tools/
    ├── build.sh                   페이지 조립 스크립트
    ├── partials/                  공통 head / header(GNB·드로어) / footer
    └── pages/*.body.html          각 페이지의 본문
```

## 4. 수정 방법

**본문만 고칠 때** — `index.html` 등 루트 HTML을 직접 편집해도 됩니다.

**헤더·푸터처럼 모든 페이지에 공통인 부분을 고칠 때** — `tools/partials/`를 수정한 뒤 재조립합니다.

```bash
bash tools/build.sh
```

`tools/build.sh`는 `tools/partials/head.html` + `header.html` + `tools/pages/<page>.body.html` + `footer.html`을
합쳐 루트에 HTML을 생성하고, 현재 페이지의 GNB 항목에 `aria-current="page"`를 자동으로 넣습니다.
빌드 결과물도 저장소에 커밋되므로 **배포 시 빌드는 필요 없습니다.**

## 5. 디자인 시스템

`assets/css/style.css` 상단의 CSS 커스텀 프로퍼티만 바꾸면 전체 톤을 일괄 변경할 수 있습니다.

**색은 장식이 아니라 의미를 나릅니다.** 화면에서 색을 보면 그것이 무엇인지 바로 알 수 있어야 합니다.

| 토큰 | 값 | 맡은 일 |
|---|---|---|
| `--navy-900` | `#08090B` | 먹색 기본 면. 헤더·히어로·기록실·푸터 |
| `--green-500` | `#00C36A` | **정체성.** 전라남도. 주요 버튼·강조어·구조선 |
| `--lime-500` | `#C6FF00` | **시계.** 오직 마감이 걸린 것에만 — 상태 스트립, D-day, 접수중 |
| `--urgent` | `#FF4D2E` | **임박.** 마감 3일 이내 (검은 글자와 조합해 AA 충족) |

라임을 아무 데나 쓰지 않기 때문에, 라임이 보이면 시간이 걸린 항목이라는 뜻이 됩니다.

- 타이포그래피: Pretendard Variable (CDN) + 시스템 한글 폰트 폴백
- 숫자는 `--font-num`으로 tabular numerals 고정 — 기록·D-day·종목 규격이 자릿수에 흔들리지 않습니다
- 라이트 / 다크 두 테마. `prefers-color-scheme`을 따르며 헤더 토글로 수동 전환(`localStorage` 저장)

### 설계 원칙

1. **운영 우선** — 협회 사이트는 홍보물이 아니라 창구입니다. 화면 최상단은 슬로건이 아니라 *지금 접수 중인 것과 마감일*이 차지합니다.
2. **숫자를 조형 언어로** — 줄넘기는 세는 운동입니다. 30초·75초·104회 같은 숫자를 장식이 아니라 화면의 주된 형태로 씁니다.
3. **가짜 이미지 자리를 만들지 않는다** — 실제 사진이 없으면 사진 자리를 비워두는 대신, 타이포와 숫자로 채웁니다. 미완성으로 보이는 플레이스홀더가 없는 편보다 나쁩니다.
4. **고아 셀 금지** — 그리드 구분선은 `gap` 배경 비침이 아니라 셀 테두리로 그립니다. 항목 수가 열 수로 나누어떨어지지 않아도 빈 칸이 회색 덩어리로 드러나지 않습니다.
5. **모션은 일을 해야 합니다** — 장식용 스크롤 애니메이션은 넣지 않았습니다. 남은 모션은 각각 역할이 있습니다: 스크롤 진행률 표시, 읽는 위치 안내, 숫자가 세어지는 느낌.

### 모션

| 기법 | 쓰임 | 미지원 브라우저 |
|---|---|---|
| `animation-timeline: scroll()` | 헤더 아래 스크롤 진행 표시줄 (JS 스크롤 리스너 없음) | `@supports`로 감싸 표시줄이 나타나지 않을 뿐 |
| `@view-transition` | 페이지 이동 시 헤더 유지 | 일반 페이지 전환으로 동작 |
| `linear()` 스프링 이징 | 버튼·카드 등 손가락이 닿는 요소 | `ease`로 대체 |
| `clip-path` 와이프 | 섹션 제목이 줄이 지나가듯 열림 | — |

주의사항 두 가지를 코드에 반영했습니다.

- `clip-path`로 잘린 요소는 IntersectionObserver가 화면 밖으로 판정합니다. 그래서 **와이프 트리거는 잘리지 않는 조상 요소**가 담당합니다. 대상 자신을 관찰하면 "가려짐 → 관찰 안 됨 → 영원히 가려짐" 교착에 빠집니다.
- 리빌 상태는 `.js` 클래스 하위에서만 적용됩니다. JS가 실패해도 콘텐츠가 사라지지 않으며, 1.2초 안전장치가 한 번 더 받칩니다.

무한 반복되는 후원사 롤링은 화면 밖으로 나가면 정지합니다(모바일 배터리).

## 6. 구현된 UI/UX

- **D-day 자동 계산** — 마감일을 `data-deadline="2026-09-10"`으로 적어두면 접속 시점 기준으로 `D-2`를 계산해 표시하고, 지난 항목은 자동으로 `접수마감` 처리합니다. 날짜를 손으로 고칠 필요가 없습니다
- **히어로 슬라이더**(서브 페이지용) — 자동재생 + 일시정지, 좌우 방향키, 마우스오버/포커스/탭 전환 시 정지, 비활성 슬라이드는 탭 순서에서 제외
- **메가 드롭다운 GNB**(≥1080px) / **슬라이드 드로어**(<1080px) — 포커스 트랩, ESC 닫기, 배경 스크롤 잠금
- **탭 · 아코디언** — WAI-ARIA 역할과 방향키(←/→/Home/End) 지원
- **스크롤 리빌 · 숫자 카운터** — `IntersectionObserver` 기반, `prefers-reduced-motion` 존중
- **일정 상태 자동 갱신** — `data-event-date="2026-11-21"`을 적어두면 접속 시점 기준으로 `종료 / 오늘 / D-n / 예정` 칩을 자동으로 바꾸고, 지난 항목은 흐리게 처리합니다. 정적 사이트라도 일정이 낡아 보이지 않습니다
- **폼** — 데모용 클라이언트 검증. 오류 시 첫 오류 항목으로 포커스 이동, `aria-live`로 결과 안내

## 7. 접근성 · SEO

- 페이지당 `<h1>` 1개, 건너뛰지 않는 제목 레벨
- 본문 바로가기 링크, 모든 아이콘 버튼에 `aria-label`, 모든 폼 컨트롤에 연결된 `<label>`
- 라이트·다크 모두 WCAG 2.1 AA 명도 대비(본문 4.5:1, 큰 글자 3:1) 충족 — 자동 스크립트로 전 페이지 검증
- 가로 스크롤 없음(430 / 768 / 1440px 검증), `prefers-reduced-motion` 대응, 인쇄 스타일 포함
- 페이지별 `<title>`·`description`·Open Graph 메타, `SportsOrganization` JSON-LD, `sitemap.xml`, `robots.txt`

## 10. 라이선스 및 저작물

`assets/img/`의 로고 파일(`logo.png`, `logo-dark.png`, `logo-mark.png`, 파비콘, OG 이미지)은
**협회가 제공한 공식 로고 원본**에서 추출·가공한 것으로, 저작권은 전남한국줄넘기협회에 있습니다.
그 외 페이지의 모든 그래픽(히어로 배경, 카드 일러스트 등)은 이 저장소에서 직접 작성한 인라인 SVG입니다.
외부 사이트의 이미지·소스·서체 파일을 복제하지 않았습니다.
외부 의존성은 CDN으로 불러오는 Pretendard 웹폰트(SIL Open Font License) 하나뿐입니다.
